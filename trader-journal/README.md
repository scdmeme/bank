# Trader Journal — AI-разбор сделок (MVP)

Прототип объединённого продукта: трейдер диктует/пишет о сделке свободным
текстом, а AI сам извлекает структуру (инструмент, направление, тезис, эмоцию
входа, результат, ошибку) и строит «психологическую карту».

## Стек

- **Next.js 16** (App Router, TypeScript, Tailwind CSS v4)
- **Auth.js (next-auth v5)** — авторизация email + пароль (JWT-сессии)
- **Prisma + SQLite** — БД для прототипа (в проде меняется на PostgreSQL)
- **OpenAI** — AI-разбор сделки; при отсутствии ключа работает встроенный
  офлайн-mock, чтобы прототип был полностью демонстрируемым
- **Web Speech API** — голосовой ввод прямо в браузере (без внешнего сервиса)

## Локальный запуск

```bash
npm install
cp .env.example .env          # заполни AUTH_SECRET (npx auth secret)
npx prisma generate
npx prisma db push            # создаёт SQLite-базу dev.db
npm run dev
```

Открой http://localhost:3000 → зарегистрируйся → опиши сделку.

### Переменные окружения

| Переменная       | Назначение                                                       |
| ---------------- | ---------------------------------------------------------------- |
| `DATABASE_URL`   | Строка подключения к БД (SQLite по умолчанию)                    |
| `AUTH_SECRET`    | Секрет Auth.js (`npx auth secret`)                               |
| `OPENAI_API_KEY` | Ключ OpenAI. Пусто → используется встроенный mock-разбор         |
| `OPENAI_MODEL`   | Модель (по умолчанию `gpt-4o-mini`)                              |
